# ![favicon](https://github.com/user-attachments/assets/8e3ec54d-697d-4713-813c-396aa4a40abb) GersangTracker
거상 트래커


거상 게임의 사냥 중 아이템 드랍을 실시간 감지하고, 시간당 수익을 계산하는 데스크탑 앱입니다.

---

## 기능

- [x] 실시간 아이템 드랍 자동 감지
- [x] 아이템 단가 입력 후 총 수익 / 시간당 수익 계산
- [x] 사냥 세션 기록 및 조회
- [x] 엑셀 내보내기 지원

---

## 빠른 시작

**다운로드**

[Releases](https://github.com/JIK-K/GersangTracker/releases) 페이지에서 최신 버전을 다운로드하세요.

**설치**

1. `GersangTracker_Setup.exe` 설치 실행
2. [Npcap 공식 사이트](https://npcap.com/#download) 에서 최신 버전 설치
3. `GersangTracker.exe` 실행

> ⚠️ `Npcap` 이 설치 되어 있지 않으면 동작하지 않습니다.
